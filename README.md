# Matriz Ordenada por Columnas - Selection Sort

**Ejercicio 18** - Algoritmos de Ordenamiento

## Descripción
Se crea una matriz numérica y se ordena **cada columna** de menor a mayor utilizando el algoritmo **Selection Sort** implementado manualmente.

## Funcionalidades
- Mostrar matriz original
- Mostrar el proceso de ordenamiento paso a paso
- Contar el número de comparaciones realizadas por cada columna
- Mostrar la matriz resultante
- Explicación de la complejidad temporal

## Cómo ejecutar
1. Abrir el proyecto en IntelliJ IDEA
2. Ejecutar la clase `MatrizOrdenadaColumnas`

## Complejidad
- Selection Sort por columna: **O(n²)**
- Complejidad total (m columnas): **O(m × n²)**
